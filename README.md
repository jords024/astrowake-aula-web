# Astrowake — Hackeando a Realidade (Apresentação Web Ao Vivo)

Apresentação Web interativa de 21 lâminas para transmissão via **Google Meet**, com:
- **Navegação por teclado** (`←`, `→`, `Espaço`, `F` para Tela Cheia, `G` para Grade de 21 Slides)
- **Teleprompter Sincronizado (`Tecla T`)**: abre uma janela separada com o script corrido de cada lâmina que atualiza automaticamente ao passar os slides (invisível para o público quando você compartilha apenas a guia principal no Google Meet).

## Como publicar na Web (GitHub Pages / Vercel / Netlify / Lovable)
Basta subir esta pasta em um repositório GitHub e ativar o **GitHub Pages** (ou importar no Vercel / Netlify / Lovable).
